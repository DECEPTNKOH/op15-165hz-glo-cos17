# Changelog

## v1.5.5
- Добавлена защита от bootloop (`boot_count` в `/data/adb/op15_165hz_glo/`): после 2 незавершённых загрузок подряд модуль пропускает монтирование XML и не перезаписывает настройки.
- В `service.sh` и `action.sh` добавлена верификация записи `settings put` через `settings get` (в `service.sh` — до 5 попыток перед фиксацией `applied_version`).
- Общая логика (`log`, `is_mounted`, `apply_165_flags`, пути) вынесена в `common.sh`; `action.sh` теперь проверяет фактическое монтирование XML в `/proc/mounts` и выводит статус `oplusscreenmode`.
- В бэкапе и `uninstall.sh` добавлена поддержка исходно отсутствующих ключей (`__UNSET__` → `settings delete`); `clamp_120` переписан на чистый POSIX `sh` без `awk`.
- Дополнена инструкция восстановления в `README.md` (файл `disable`, APatch, напоминание о ручном откате флагов после отключения модуля).

## v1.5.4
- Атомарное монтирование обоих XML в `post-fs-data.sh` с откатом (`umount`) при ошибке второго файла.
- Проверка факта монтирования через `/proc/mounts` и отсутствия непатченных `targetFramerate="120"`.
- Строгая проверка пары `OP611FL1` и `CPH2747` в `customize.sh` + снятие бэкапа настроек при первичной установке.
- Автотест XML-патчера и валидация структуры XML в GitHub Actions.

## v1.5.3
